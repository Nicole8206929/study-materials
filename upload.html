上传书籍

手机自带浏览器 · GitHub 私有上传区。

自动识别、跳过已上传文件并补齐缺失项，目前尚未实现。

下面的入口打开 GitHub 自己的 Edit release 上传页面。它不会因为书架代码更新就自动跳过重复文件；本网站无法修改 GitHub 原生上传程序。

已撤下书签和插件安装引导，不需要按旧说明安装或运行它们，也未启用新的上传后台。当前入口保留用于访问原有资料，不代表已经满足自动补传要求。

打开 GitHub 私有上传区

使用有权访问资料库的 GitHub 账号登录，找到“书籍上传区”的编辑按钮。公开书架与试读仍不需要登录。

出现“同名附件已存在”

“An attachment with that filename already exists”表示 GitHub 已有同名附件，不能由此判断其他文件是否已经上传。直接在原生页面重新全选，仍可能出现此提示。

已有的成功附件继续保留，不需要为了清除同名提示把它们删除。若刚上传了新文件，等待完成后点 Save draft 保存草稿，不需要点 Publish release。

资料整理

完整原件保留在私有资料库，公开书架只展示书目和有限试读。上传后回到聊天说明已上传的资料，再核对文件并按约定整理；本入口不会自动生成讲义或删除原件。
