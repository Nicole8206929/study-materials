首次启用自动入库

完成这一次，之后自己选分类并上传即可。

完整文件在私有仓库，公开书架在另一个仓库。GitHub 自动任务需要一份仅用于更新公开书架的授权；当前 ChatGPT 的 GitHub 连接不能代设这项仓库密钥。无需安装扩展、开启服务器或把令牌发到聊天。

  1. 在 GitHub 创建书架授权。

    下方链接预填账户与 Contents: Read and write（仓库内容读写）。在 Repository access 选择 Only select repositories，并且只选 study-materials，再创建并复制令牌。无需授权其他仓库或账户管理权限；到期后需更新同一项密钥。

    创建书架授权
  2. 保存到 GitHub 的私有仓库密钥。

    打开下方页面，Name 填 PUBLIC_SHELF_TOKEN，Secret 粘贴刚才的令牌，然后点 Add secret。只在 GitHub 页面粘贴；本网站不接收令牌。

    保存发布授权
  3. 启用并检查一次。

    打开下方任务页，点 Run workflow。保持 release_id 留空，直接运行。任务验证发布权限并更新网站后，上传页会显示“自动入库已启用”。之后上传无需再运行这一步。

    启用自动入库

以后在上传页选择分类、标签和整理方式，去 GitHub 添加文件并点 Publish release。完整文件仍在私有仓库；公开书架只增加书目信息和最多 10 页试读。

返回上传页检查

未启用或整理失败时，原件保持私有并保留，不会假报上传成功。
