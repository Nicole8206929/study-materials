## 从微信上传书籍

书架顶部的“上传书籍（仅本人）”打开 `upload.html`，提供安卓手机操作说明，并跳转到私有仓库的 Releases 上传区。草稿的 untagged 地址可能改变，入口不固定旧地址。微信文件先保存到手机，再选择附件上传；每个文件须小于 2 GiB。等待完成后点击 Save draft，不需要发布 Release。需要时在 GitHub 登录本人账号，书架本身不新增登录或密码。

当前采用用户选择的“手机本地核对并生成仅缺失文件补传包”：从聊天打开本批私人核对链接，可多次追加原 PDF／PPT／PPTX（例如 50＋47 累计到 97，最多 1000），页面按内容 SHA256 和准确大小跳过已成功文件，将缺失原件打成一个 ZIP 下载，再由用户把这个 ZIP 上传到原 GitHub 草稿。无需逐个挑文件、书签、扩展或新后台。原生 GitHub 上传页本身的行为未改变，已上传原件不删除。

已上传记录由私有仓库工具加密导出，仅含大小和内容校验值；公开目录 `upload-check-data/` 只存 AES-GCM 密文，解密信息在私人链接的片段中，不发送给网站服务器。公开入口不包含解密信息、GitHub 凭据或原件。核对及打包在手机本地按 256 KiB 读取，打包使用原 File 片段，禁止将整本资料缓冲进单个 ArrayBuffer。结果是保留原文件内容的 ZIP，不是讲义改写或压缩 PDF。

记录是带时间的快照，不能宣称实时同步。新包上传后，助手重新核验，可用同一私人链接刷新加密记录；页面返回前台时重新读取。首次从聊天中的完整链接进入；成功载入后只在本机记住核对入口，不保存所选文件或 GitHub 登录信息。普通上传入口可恢复本机最近成功载入的记录。没有记录时仍可先选文件，待完整链接恢复或重试成功后自动继续；禁止把未加载当作零成功记录。请求 20 秒超时可重试，脚本启动失败也有明确提示。已合订批次显示归档历史，不将已清理的源附件说成仍在线。私人链接不要提交到公开仓库。OPPO／vivo 真机仍需验证，不把 Chromium／Firefox 的模拟验收说成真机成功。

核对和打包期间在支持的浏览器请求 Screen Wake Lock，切到后台释放、返回前台重新申请，处理结束后释放。返回后保留所选 File、已完成的内容哈希与仍有效的 ZIP；刷新记录仅在清单内容改变时使旧包失效并重核对。离线刷新失败保留当前结果，重新联网重试。系统终止网页后不能恢复 File，需要重选；本页没有接管 GitHub 原生传输，也不能绕过系统限制保证黑屏上传。云端合订任务启动后独立运行。

已选文件列表每项提供“×”，支持清空和撤销移除，仅调整当前页面的选择，不删除手机或 GitHub 原件。核对／打包中也可追加或移除，旧任务被取消并按最新选择重新核对；旧 ZIP 下载链接立即失效，已下载到手机的旧包不会被修改。已验证的 File 对象在本页缓存 SHA256，追加新批次不重读仍保留的文件。选择器取消扩展名过滤，系统浏览器允许时可按文件夹递归添加课件；网页不能突破手机单次选择数量、微信受保护目录或整机读取权限，不能宣称单次已支持 1000 个。

构建：`npm run build:checker` 生成 `assets/upload-checker.js`，更改源代码后需重新生成并提交；`npm test` 校验产物一致性并测试判重、取消、ZIP 可读性、内容保真、无文件网络传输和手机布局。旧书签／扩展源码仅保留审查，不提供安装操作，不作为当前上传方案。

上传后回到聊天告诉助手“已上传”。普通单本 PDF／EPUB 通过私有仓库的 `scripts/import_release_books.py` 增量导入；本批 ZIP 先核验成员并与既有原件去重，再衔接既定原页合订流程，不能直接把 ZIP 当作一本书或一份源课件。确认分类、生成有限试读后，再分别提交私有处理记录与公开书架。此入口不是本站上传 API，也不会自动同步或自动生成讲义。网络失败的附件需要重传，不承诺断点续传。

以前已被别人下载或缓存的公开副本无法追回。此改动限制的是迁移后的公开站点与仓库访问。

## 本地运行和检查

```bash
python3 -m http.server 8000
python3 scripts/check_public_shelf.py
npm ci
npx playwright install chromium firefox
npm test
```

只提交试读图片和公开书目信息，不要将原件、压缩包、令牌或环境文件放回公开仓库。CI会检查原件扩展名、目录中的下载路径及试读数量。

生成试读时使用私有原件仓库中的 `scripts/build_public_shelf.py`，在独立目录生成新的公开发布内容，再运行上述检查。不要将私有仓库的历史推送到此仓库。

书籍权利归原作者或出版方所有，根目录MIT许可仅覆盖自有代码，不代表第三方书籍授权。

分类列表由 `books.json` 的 `categories` 字段维护。空分类也会显示，选择后显示“暂未添加书籍”；其筛选网址可分享并在刷新后保留。新增书籍时使用对应分类 ID，无须再修改页面代码。
