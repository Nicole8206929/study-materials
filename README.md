# Nicole 的公开学习书架

网址：https://nicole8206929.github.io/study-materials/

无需登录或入口密码。按“心理、经济、金融、管理、会计、统计、生物、高中物理、大学物理、高中数学、竞赛数学、大学数学”分类，可按中文书名、英文书名和常用名称搜索。

每本书展示锁图标，并仅提供前10页的图片试读。本站不包含完整PDF/EPUB，不提供完整原件下载，也不使用能被绕过的前端下载密码。已公开的试读图片仍可被截图或保存。

完整原件和包含原件的旧Git历史已迁移到私有仓库 `Nicole8206929/study-materials-originals`。所有者需要取回完整文件时，应通过自己的GitHub账户进入该私有仓库；公开网页不会识别所有者，也没有单独的所有者下载入口。

以前已被别人下载或缓存的公开副本无法追回。此改动限制的是迁移后的公开站点与仓库访问。

## 本地运行和检查

```bash
python3 -m http.server 8000
python3 scripts/check_public_shelf.py
npm ci
npx playwright install chromium
npm test
```

只提交试读图片和公开书目信息，不要将原件、压缩包、令牌或环境文件放回公开仓库。CI会检查原件扩展名、目录中的下载路径及试读数量。

生成试读时使用私有原件仓库中的 `scripts/build_public_shelf.py`，在独立目录生成新的公开发布内容，再运行上述检查。不要将私有仓库的历史推送到此仓库。

书籍权利归原作者或出版方所有，根目录MIT许可仅覆盖自有代码，不代表第三方书籍授权。

分类列表由 `books.json` 的 `categories` 字段维护。空分类也会显示，选择后显示“暂未添加书籍”；其筛选网址可分享并在刷新后保留。新增书籍时使用对应分类 ID，无须再修改页面代码。
